# 拾趣图标

正式图标已按用户最终附图定稿：白毛红瞳猫耳少女，从酒红圆角图标右下角斜向探头，头脸向左上展开。采用红色实心椭圆眼睛和张开的小嘴，保持简洁色块和少量刘海。

- `app-icon-final.png`：用户最终选定的附件原文件，逐字节保留，圆角外透明；构建图标的唯一正式来源。
- `app-icon-v5.png`：之前进一步压扁脸型的方案，保留存档。
- `app-icon-v4.png`：之前扩大脸部范围的方案，保留存档。
- `app-icon-v3.png`：之前的右下角探头方案，保留存档。
- `app-icon-v2.png`：之前从右侧探头的猫耳方案，保留存档。
- `app-icon-v1.png`：之前的蓝发方案，保留存档。
- `app-icon.ico`：Windows 图标容器，包含 16、24、32、48、64、128、256 px 七种尺寸。
- `app-icon-32.png`：32 px 图标副本。
- `app-icon-64.png`：内嵌的窗口与界面品牌图标，也用于较大预览。

各候选图原本使用内置 image_gen 工具制作，历史提示词保留存档。最终定稿直接采用用户附图，原图不作修改。导出时收紧外圈透明画布（每侧 5.5%），再等比例缩放和封装 ICO，以增加任务栏内的实际图案占比；窗口资源使用 64 px 版本，改善高 DPI 缩放。

图标已经接入 EXE、托盘、管理窗口、选择器和设置窗口。重新生成多尺寸文件：

```powershell
.\scripts\Build-Icon.ps1
.\build.ps1
```
